# Evaluation consent script (5–10 student pilot)

This script is for a future supervised study. No pilot has been run.

1. Explain that TermPilot organises authorised sources and does not complete assessed work.
2. Show the synthetic scenario. Real university credentials are out of scope for this protocol.
3. Confirm the student may stop at any time.
4. Record a participant code, not a name.
5. Collect only the survey fields in `schema.csv`.
6. Do not infer health, disability or academic ability.
