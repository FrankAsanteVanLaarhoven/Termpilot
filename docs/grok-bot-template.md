# Sharing TermPilot as a Grok Bot template

Grok Bot templates are blueprints: identity, description, instructions, selected memories, skills and first-party plugins. They exclude secrets, custom code, MCP servers and personal memories.

TermPilot's shareable recipe lives in `grok/template/`.

Student Build Challenge post should include:

1. What the bot does and which tools it uses — `docs/linkedin-post.md`
2. A video of it in action — `docs/demo/termpilot-in-action.mp4`
3. Shared Bot template — `grok/template/PROFILE.md` and `INSTALL.md` (publish **Share as template** in the Grok Bot app for an `https://x.ai/bot/...` link)
4. `#GrokBotForStudents`

VoiceBridge is an accessibility layer. The submission remains valid if live xAI STT/TTS is unavailable; the browser speech APIs are a labelled fallback.
