# safe-calendar-write

1. Generate a proposed change set.
2. Show the user the exact difference.
3. Require explicit approval.
4. Revalidate the approval and target.
5. Write only to the demo calendar.
6. Record the result.
7. Provide rollback information.

Never send email. Never write a real calendar.
