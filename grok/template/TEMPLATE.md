# TermPilot Grok Bot template

Shareable Bot recipe for the Student Build Challenge. Others can **Add to Grok Bot** or paste [`PROFILE.md`](./PROFILE.md).

**Install:** [`INSTALL.md`](./INSTALL.md)

Included:

- Bot identity and never-list ([`BOT.md`](./BOT.md), [`PROFILE.md`](./PROFILE.md))
- Skills: extract-obligations, verify-deadlines, build-feasible-plan, safe-calendar-write, privacy-and-integrity-check
- Non-personal memories ([`memories.md`](./memories.md))
- First-party plugin *names* only ([`plugins.json`](./plugins.json))

Excluded (Grok Bot template rules):

- Secrets and API keys
- Custom MCP servers
- Personal / student memories
- Real LMS, mailbox or calendar credentials

Hashtag: `#GrokBotForStudents`
