# privacy-and-integrity-check

Block:

- Homework completion requests
- Impersonation
- Unauthorised source access
- Collection of health, disability or ability inferences
- Sending messages without approval
- Hidden monitoring
- Storage of unnecessary raw email bodies

Return `allow`, `block` or `escalate` with a reason code.
